## What is Calcolo?

Calcolo is a calculator CLI built in Rust that allows you to write mathematical formulas using LaTeX notation.
You can use familiar LaTeX notation directly as input, such as `\frac{1 + \sqrt{5}}{2}`.
In addition to simple calculations, you can also save values like `let x = ...` and execute multiple expressions together in a single file.
