## Calcoloとは

Calcoloは、Rustで構築された、LaTeX記法で数式を書ける電卓CLIです。
`\frac{1 + \sqrt{5}}{2}` のように、LaTeXでおなじみの記法をそのまま入力として使えます。
簡単な計算はもちろん、`let x = ...` のように値を保存しながら、複数の式を1つのファイルにまとめて実行することもできます。
